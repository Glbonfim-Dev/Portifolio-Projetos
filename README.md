# Portfólio — Guilherme Bonfim

Portfólio profissional desenvolvido para apresentar minha experiência em **Planejamento e Controle da Produção (PCP)**, dados industriais, automação e melhoria de processos.

O site reúne minha trajetória profissional, formação acadêmica, cursos, conhecimentos, projetos desenvolvidos, currículo e formas de contato.

## Funcionalidades

- Apresentação do perfil e da experiência profissional;
- Exibição de conhecimentos em PCP, ERP, Power BI e Excel;
- Formação acadêmica e cursos relevantes;
- Visão integrada de cinco projetos, com ícones e suas etapas no PCP;
- Acesso à apresentação única **Digitalização do PCP**, em PDF com 11 páginas;
- Download e visualização do currículo;
- Formulário para preparação de contato por e-mail;
- Navegação responsiva para computadores, tablets e celulares;
- Recursos de acessibilidade e suporte à navegação por teclado.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Projetos apresentados

- Agente de Nesting — entrada de dados;
- Apontamento Agrupado — execução;
- Carga Máquina — programação;
- Painel de Montagem — acompanhamento;
- Dashboard Gerencial — gestão.

O botão **Explorar apresentação completa** abre o PDF que reúne os cinco projetos.

## Como visualizar

1. Faça o download ou clone este repositório:

```bash
git clone https://github.com/Glbonfim-Dev/Portifolio-Projetos.git
```

2. Acesse a pasta do projeto baixado ou clonado.
3. Abra o arquivo `index.html`, localizado na raiz, em seu navegador.

O projeto utiliza apenas tecnologias web nativas, por isso não é necessário instalar dependências.

Versão online: [Portfólio de Guilherme Bonfim](https://glbonfim-dev.github.io/Portifolio-Projetos/).

## Atualização das apresentações

Os PDFs ficam na pasta `Apresentação`. Ao trocar o nome de um arquivo, atualize também os links correspondentes no `index.html`. Para o currículo, ajuste tanto o botão **Ver currículo** quanto o link **Baixar currículo**, incluindo o nome no atributo `download`.

Para atualizar a versão online, publique os arquivos alterados e os PDFs correspondentes no repositório utilizado pelo GitHub Pages.
